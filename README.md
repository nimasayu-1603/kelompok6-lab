# Proyek Kelompok 6: Sistem Laporan Cepat Inventaris Lab
# 1. Masalah yang Dipecahkan
Pencatatan inventaris dan laporan kerusakan perangkat komputer lab saat ini masih dilakukan secara manual. Hal ini sering luput, tidak terdata dengan rapi, dan menyulitkan saat pembuatan laporan di akhir semester.
# 2. Gagasan Solusi Kami
Kami membuat **Form Laporan Cepat via Google Form** yang terintegrasi langsung dengan **Dashboard / Rekap Otomatis (Google Sheets)**. 
# 3. Siapa Penggunanya?
  **Siswa (RPL / DKV):** Sebagai pelapor jika menemukan kerusakan komputer.
  **Laboran & Kepala Jurusan:** Sebagai pengelola data inventaris dan penerima laporan otomatis.
# 4. Apa yang Membuatnya Baru?
Siswa tidak perlu lagi melapor manual menggunakan kertas atau papan tulis. Laporan bisa diakses cepat via link/shortcut, dan data langsung terupdate secara *real-time* di dashboard.
# 5. Mengapa Gagasan Ini Dipilih?
Karena sangat realistis untuk diterapkan secara cepat, tidak membutuhkan biaya tambahan (hemat biaya), serta ramah pengguna (user-friendly) baik bagi siswa maupun pengelola lab.
# Aturan Curah Gagasan (Dokumentasi)
  **Target Ide:** Minimal 15-20 ide (fokus pada kuantitas dulu, kualitas belakangan).
  **Aturan Penting:** Dilarang men-judge atau mengejek ide teman. Ide aneh tetap dicatat dan boleh ditambahkan/dikembangkan.
  **Metode:** Sistem muter meja (1-2 menit per orang). Jika belum ada ide, boleh bilang "pass" dan menunggu putaran kedua.
